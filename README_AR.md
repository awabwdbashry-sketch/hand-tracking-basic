# Hand Tracking Basic ✋

مشروع لتتبع اليد في الوقت الحقيقي باستخدام **OpenCV** و **MediaPipe Hands**.

يستخدم المشروع كاميرا الويب لاكتشاف اليد وتتبع نقاطها الرئيسية وعرضها مباشرة على الشاشة.

## ✨ المميزات

- اكتشاف اليد في الوقت الحقيقي
- تتبع نقاط اليد الرئيسية
- دعم تتبع يدين في نفس الوقت
- رسم نقاط اليد والروابط بينها
- استخدام كاميرا الويب للتتبع
- عرض النتائج بشكل مباشر

## 🛠️ التقنيات المستخدمة

- Python
- OpenCV
- MediaPipe
- NumPy

## ⚙️ طريقة عمل المشروع

تقوم كاميرا الويب بالتقاط الفيديو في الوقت الحقيقي.

بعد ذلك يقوم **MediaPipe Hands** بتحليل كل إطار من الفيديو واكتشاف اليدين ونقاطهما الرئيسية.

يقوم المشروع بعد ذلك برسم نقاط اليد والروابط بينها على صورة الكاميرا.

يمكن للمشروع تتبع ما يصل إلى يدين في نفس الوقت.
