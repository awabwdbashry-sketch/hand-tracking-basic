# ✋ تتبع اليد الأساسي

مشروع بسيط لتطبيق **تتبع اليد Hand Tracking** في الوقت الحقيقي باستخدام Python وOpenCV وMediaPipe.

يستخدم المشروع كاميرا الويب لاكتشاف يد المستخدم وتتبع نقاطها في الوقت الحقيقي، وهو مصمم ليكون مقدمة عملية وبسيطة لفهم تقنية تتبع اليد باستخدام MediaPipe ومفاهيم الرؤية الحاسوبية.

---

## ✨ المميزات

- 📷 استخدام كاميرا الويب في الوقت الحقيقي
- ✋ اكتشاف اليد بشكل مباشر
- 🎯 تتبع نقاط اليد
- 🧩 تحديد بنية اليد والنقاط الرئيسية
- 🖥️ عرض مباشر لصورة الكاميرا
- ⚡ معالجة في الوقت الحقيقي
- 🐍 تطبيق بسيط باستخدام Python
- 🎓 مناسب كبداية لفهم تقنية MediaPipe Hand Tracking

---

## 🛠️ التقنيات المستخدمة

- 🐍 **Python**
- 📷 **OpenCV** — التقاط الكاميرا ومعالجة الصور
- ✋ **MediaPipe** — اكتشاف اليد وتتبع نقاطها

---

## ⚙️ كيف يعمل المشروع؟

يقوم التطبيق بالتقاط الصور من كاميرا الويب بشكل مستمر ثم تمريرها إلى نظام تتبع اليد.

يقوم MediaPipe باكتشاف اليد وتحديد نقاطها، بينما يستخدم OpenCV لعرض صورة الكاميرا مع نقاط وبنية اليد المكتشفة.

### 🔄 مراحل المعالجة

```text
Webcam
   ↓
OpenCV
   ↓
MediaPipe
   ↓
Hand Detection
   ↓
Hand Landmarks
   ↓
Live Visualization
```

## ✋ نقاط اليد

يقوم MediaPipe باكتشاف مجموعة من النقاط التي تمثل بنية اليد.

ويمكن استخدام هذه النقاط كأساس لبناء العديد من تطبيقات الرؤية الحاسوبية المتقدمة، مثل:

- 👆 عد الأصابع
- ✋ التعرف على الإيماءات
- 🖱️ التحكم بالماوس عن طريق اليد
- 🎨 الرسم في الهواء
- 🎮 الألعاب التي تعتمد على الإيماءات
- 🤖 التفاعل بين الإنسان والكمبيوتر

يركز هذا المشروع على المرحلة الأساسية لتتبع اليد قبل إضافة منطق التفاعل والوظائف المتقدمة.

## 📷 معالجة الكاميرا

توفر كاميرا الويب تدفقاً مستمراً من إطارات الفيديو.

في كل إطار:

1. 📷 يتم التقاط صورة من الكاميرا.
2. 🔄 يتم تجهيز الصورة لمعالجتها بواسطة MediaPipe.
3. ✋ يبحث MediaPipe عن اليد.
4. 🎯 يتم اكتشاف نقاط اليد.
5. 🖥️ يتم عرض النقاط على صورة الكاميرا.
6. 🔁 تستمر العملية مع الإطار التالي.

وبذلك يمكن تتبع اليد بشكل مستمر وفي الوقت الحقيقي.

## 📦 التثبيت

### 1️⃣ تحميل المشروع

```bash

```

### 2️⃣ الدخول إلى مجلد المشروع

```bash
cd hand-tracking-basic
```

### 3️⃣ إنشاء بيئة افتراضية

```bash
python -m venv venv
```

### 4️⃣ تفعيل البيئة الافتراضية

#### Windows

```bash
venv\Scripts\activate
```

#### Linux / macOS

```bash
source venv/bin/activate
```

### 5️⃣ تثبيت المكتبات

```bash
pip install -r requirements.txt
```
